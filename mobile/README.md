# Android live test

This is an Expo Go test app connected to the same Supabase project.

1. Copy `.env.example` to `.env` and add the Supabase publishable key.
2. Run `npm install`.
3. Run `npx expo start`.
4. Install Expo Go on the Android phone and scan the QR code.

For the first live test, the kiosk lets you select an employee and record Shift In / Break Out / Break In / Shift Out. Face recognition will be added after the database and kiosk flow are verified.
